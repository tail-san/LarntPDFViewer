# Larnt PDF Viewer

Windows向けの軽量・多機能なPDFビューアー＆編集ツールです。  
インストール不要で、ZIPを解凍するだけですぐに使えます。

## 主な機能
* **PDFビューアー**: 高画質表示、マルチタブ、蛍光マーカー・文字修正パッチ、注釈の原本保存
* **複数PDFの結合**: 一覧からドラッグで並び替えて1つに統合
* **ページの個別抽出**: サムネイルを見ながら必要なページを選択して保存
* **全ページ一括分割**: 1ページずつのファイルにまとめて分割出力
* **PDF ⇔ 画像 相互変換**: PDFから画像（PNG/JPEG）への書き出し、画像からPDFへの作成
* **PDFページの回転**: プレビューを見ながら向きを一括補正して保存
* **PDF一括リネーム**: 請求書や領収書の日付・金額・会社名を自動判定してリネーム
* **ダークモード / ライトモード対応**

## 使い方
1. 右側の **[Releases](../../releases)** から最新の ZIP をダウンロード
2. ZIP を解凍し、中にある `LarntPDFViewer.exe` を実行

## 動作環境
* Windows 10 / 11 (64-bit)
